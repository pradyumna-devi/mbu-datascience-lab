## Overview
A human expresses emotions in many forms including text, speech, and gestures. Text Emotion Detection is a content-based Natural Language Processing classification problem that trains machine learning models to detect emotions (Happy, Sadness, Anger, Fear, Love, Surprise) from short messages and pairs each detected emotion with a context-appropriate emoji.

### Tech Stack & Key Concepts
- **Natural Language Processing (NLP)**
- **Text Preprocessing & Tokenization**
- **TF-IDF Vectorization & N-grams**
- **Multinomial Naive Bayes**
- **Logistic Regression Classifier**
- **Multi-Class Evaluation (Accuracy, Precision, Recall, F1)**
- **Real-Time Emoji Mapping**
